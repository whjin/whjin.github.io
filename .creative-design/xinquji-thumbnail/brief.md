# wuhuajin 产品缩略图 Brief（v2 贴合网站 UI）

## 主题
wuhuajin 产品缩略图 —— 面向新趣集（xinquji.com）发布表单的产品展示图。**v2 依据 wuhuajin.com 真实 UI 重新设计**（第一版深色玻璃风格与网站不符，废弃）。

## 商品
wuhuajin.com —— 吴华锦的个人主页：一个 JavaScript / Node.js / 前端技术博客，浅色简约技术博客风格。

## 网站真实 UI（设计依据，已从源码确认）
- **banner 渐变**：`linear-gradient(90deg, #007bff 0%, #5b6ee1 100%)`（蓝 → 蓝紫）
- **主色**：`#007bff`（导航圆钮、链接、强调元素）
- **强调紫**：`#8b5cf6`（卡片边框、点缀）
- **背景**：纯白 `#ffffff`、浅灰 `#f8f9fa`、淡紫 `rgba(139,92,246,.04)`
- **视觉特征**：浅色、留白充足、白色卡片、蓝紫主元素、圆角、简洁技术感
- **导航**：右下角圆角蓝色半圆按钮（fixed 右上角，`#007bff` 圆角）

## 用途与交付
- 新趣集「产品缩略图」，240×240px。
- 生成 1:1 方图（1024×1024），缩放到 240×240 后主体清晰。

## 画幅
- 1:1 正方形（1024×1024）

## 传播目标
- 第一视觉：一眼识别「前端 / JavaScript 技术博客」，浅色清爽。
- 随后感知：与网站一致的蓝紫渐变、白底卡片、代码元素。
- 期望情绪：专业、干净、科技感、可信。

## 核心主体
- 浅色底（白 / 浅灰），中央一个简洁的代码符号 `</>` 或 JS 花括号 `{}`，用蓝→蓝紫渐变填充。
- 主体放在白色圆角卡片上，卡片边缘带浅蓝/浅紫描边（呼应网站卡片风格）。
- 可加一条顶部细渐变条（`#007bff → #5b6ee1`），呼应网站 banner。
- 背景留白，少量淡紫/淡蓝圆形光斑点缀，保持简约。

## 构图
- 方形居中，主体约 55%-65%。
- 白色卡片居中，渐变细条在顶部或环绕，视觉焦点在中央代码符号。
- 小尺寸下清晰，不依赖细小文字。

## 视觉语言
- 媒介：扁平 / 轻拟物 UI 风格插画。
- 色彩：主 `#007bff`、渐变到 `#5b6ee1`、紫 `#8b5cf6`，白底浅色。
- 光线：柔和、无强烈深色阴影。
- 材质：白色卡片、轻微圆角、细渐变描边。

## 可见文字
- 无正文文字（小尺寸保持清晰）；如品牌可加极简 "wuhuajin" 小字，以可读性为准。

## 禁止项
- 不做深色背景、不做玻璃拟态、不做发光电路、不出现水印/签名/乱码文字。
- 必须贴合网站浅色蓝紫科技风。

## 质量目标
- 主体结构清晰、边缘干净、小图可辨识、配色严格对应网站。
- 1024×1024 正方形，无拉伸。
