## 四、Hexo 式 feed 数据源（已切换，正式方案）

原「第 2 步」在 menu/data.json 手写 feed 字段，经确认改为 **Hexo 式：feed 数据从文章自身提取**（单一数据源，不再手工维护第二份元数据）。

### 数据流
```
文章 .md 顶部 front matter ──► scripts/build-feed.cjs ──► src/template/feed/data.json
                          （发布前运行 / npm 手动运行）          （首页 feed 渲染读它）
                                  │
                                  └──► menu/data.json「原创文章」卡仅同步 title+url（导航用）
```

### 文章 front matter（按需填写，模板仅供参考）
```yaml
---
title: 文章标题
date: 2026-09-26
category: AI
tags:
  - AI
  - 学习路线
description: 摘要（feed 卡显示）
sticky: 1        # 置顶精选 featured（仅精选篇写）
published: true  # false 则不进 feed
cover:           # 封面（可选）
---
```
`readTime` 由生成器按正文自动计算；`url` 由目录+文件名自动推导。**字段可缺省**，生成器有兜底（title=文件名、category=目录、date=文件时间、description=自动摘要）。

### 已落地改动
- 42 篇 `.md` 全部补齐 front matter（title/date/category/description；5 篇精选带 `sticky:1`）。
- `scripts/build-feed.cjs`：扫描 posts → 解析 front matter → 生成 `feed/data.json`（42 篇、5 featured）→ 精简 menu「原创文章」为 title+url。
- `scripts/add-front-matter.cjs`：一次性批量补 front matter（已执行，幂等：已有 front matter 跳过）。
- `src/components/render/index.js`：渲染时**剥离文章顶部 front matter**，正文页不显示 front matter。
- `Deploy.sh` / `Deploy.command`：发布前自动运行 `node scripts/build-feed.cjs`（git add 之前）。
- menu/data.json 的「原创文章」卡已**去除 feed 字段**（home/featured/category/date/readTime/excerpt 等统一移除），feed 字段只存在于 `feed/data.json`。

### 新文章 / 改文章流程（Hexo 式）
1. 在 `src/template/posts/{分类}/{文件名}.md` 写正文，顶部填 front matter。
2. 发布时 `Deploy.command`（或手动 `node scripts/build-feed.cjs`）自动重新生成 feed → 首页自动更新。

> 说明：`feed/data.json` 与 menu 的「原创文章」卡均为**生成物**（由 front matter 驱动），非手工维护。
